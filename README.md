# ⚽ Statlyx — Football Scouting & Intelligence Platform

A high-performance sports analytics web application tracking **2,839+ professional football players** across Europe's top 5 leagues (Premier League, La Liga, Bundesliga, Serie A, Ligue 1). Built with React, TypeScript, Tailwind CSS, and Python data pipelines.

---

## ✨ Features

- **Master Player Roster**: Search and filter 2,839+ players by name, club, position (`FW`, `MF`, `DF`, `GK`), or age range with instant 24-card progressive batch rendering.
- **Athlete Scouting Profiles**: Multi-axis radar skill profiles, historical market valuation curves, tabbed metrics, and similar player recommendations.
- **Head-to-Head Comparison Matrix**: Compare any two players side-by-side with dual-polygon radar overlays, statistical leader badges, and advantage cards.
- **League Intelligence & Insights**: Top goal scorers by division, positional physical workloads, and biological age peak distribution histograms.
- **Security Hardened**: Client-side XSS input sanitization and production HTTP security headers (`nosniff`, `X-Frame-Options: DENY`, `X-XSS-Protection`).

---

## 🤖 Data Analytics & Machine Learning Pipeline

The project includes a dedicated Python pipeline (`build_data.py`) powering statistical calculations and similarity algorithms:

- **Vector Cosine Similarity ($k$-NN)**: Computes $n$-dimensional positional feature vectors to find the top 5 most similar athlete profiles for any player:
  $$\text{Cosine Similarity} = \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\|_2 \|\mathbf{v}\|_2}$$
- **Positional Cumulative Percentile Normalization**: Normalizes player statistics relative to their exact positional peers (Forwards, Midfielders, Defenders, Goalkeepers) to power multi-axis skill radar charts.
- **Fuzzy Entity Matching**: Uses Levenshtein distance sequence matching ($\ge 80\%$) to resolve player names and club entities across raw CSV datasets.

## 🔗 Data API Endpoints (Static JSON API)

The application utilizes a **Jamstack REST Data Architecture** with segmented JSON endpoints generated by the Python analytics pipeline:

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/data/players.json` | Fetch summary stats and market values for all 2,839 players |
| `GET` | `/data/player_details/{id}.json` | Fetch full attribute radar, statistics, and valuation history for a specific player |
| `GET` | `/data/league_summaries.json` | Fetch top goal leaders, positional workloads, and age distribution by division |

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/AmaanJilani1/statlyx.git
cd statlyx
```

### 2. Frontend Setup

Navigate to the frontend folder:
```bash
cd football-dashboard/frontend
```

Install dependencies:
```bash
npm install
```

Start the development server:
```bash
npm run dev
```

Frontend will start on:
```
http://localhost:5173/
```

Production build verification:
```bash
npm run build
```

### 3. Data Pipeline (Optional)

Navigate to the data pipeline folder:
```bash
cd football-dashboard/data-pipeline
```

Install dependencies:
```bash
pip install pandas numpy rapidfuzz
```

Run the pipeline:
```bash
python build_data.py
```
